A vintage travel poster for a place that does not exist: **LUMARIS — The Floating Isles**, made for the make.fun bounty [The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539). A chain of lush floating islands drifts above a sea of golden clouds at sunset, waterfalls spilling off their edges into the clouds below, a small airship crossing between them.

> Above the clouds. Beyond the map.

## The poster

- One dominant image: floating islands, waterfalls, a golden sunset sky, and a lone airship — drawn in a classic 1930s lithograph travel-poster style.
- Big bold typography: **LUMARIS**, **THE FLOATING ISLES**, and the tagline *Above the clouds. Beyond the map.*
- 1024x1024, high contrast, readable at small sizes.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.png — a byte-identical copy of entry.png
```

`main.ts` needs only the Node standard library and no network access.
The image itself is `entry.png` (1024x1024 PNG), drawn for this entry.
